### Partie I :

1- Etude de l'hydrolyse d'un ester :

1-1-1- * Formule semi-développée de l'ester E : CH3−CH2−COO−CH2−CH3
* Son nom : propanoate d'éthyle

1-1-2- Détermination de la masse de l'acide formé à l'équilibre chimique :

- La constante de l'équilibre est : K = [acide]éq × [alcool]éq / ([ester]éq × [eau]éq) avec [X] = n(X)/Vsol

- Tableau d'avancement de l'hydrolyse :

| Equation de la réaction | C2H5COOC2H5 + H2O ⇄ C2H5COOH + C2H5OH | | | |
| --- | --- | --- | --- | --- |
| Etat du système | Avancement x (mol) | n(ester) | n(eau) | n(acide) = n(alcool) |
| Etat initial | 0 | 0,1 | 0,1 | 0 |
| Etat intermédiaire | x | 0,1 − x | 0,1 − x | x |
| Etat d'équilibre | xéq | 0,1 − xéq | 0,1 − xéq | xéq |

On écrit : K = xéq2/(0,1 − xéq)2 ; on obtient : xéq = 0,1×√K/(1 + √K) (avec 0 < xéq < 0,1 mol)

On retient la solution convenable : xéq = 0,1×√0,25/(1 + √0,25) ≈ 0,033 mol

- La masse de l'acide formé à l'équilibre est : m = xéq.M(C2H5COOH) ≈ 0,033×74 ≈ 2,44 g

1-2-1- Equation de la réaction :

C2H5COOC2H5 + HO- → C2H5COO- + C2H5OH

1-2-2- Rendement de cette réaction :

r = nexp(alcool)/nthéorique(alcool) = (mexp/M(C2H5OH))/(m0/M(E)), ou bien : r = (mexp/m0)×M(E)/M(C2H5OH)

A.N : r = (4,2/10,2)×(102/46) = 0,91 = 91%

2- Etude d'une solution d'acide propanoïque :

2-1-1- Equation chimique de la réaction entre l'acide propanoïque et l'eau :

C2H5COOH(aq) + H2O(l) ⇄ C2H5COO-(aq) + H3O+(aq)

2-1-2- Expression du pH : D'après le cours on a la relation suivante :

pH = pKA + log([C2H5COO-]/[C2H5COOH])

2-1-3- Taux d'avancement final τ :

On a : τ = xf/xm = [H3O+]/C ; ou bien

τ = [H3O+]/([C2H5COO-] + [C2H5COOH]) = [H3O+]/([H3O+] + [C2H5COOH]) = 1/(1 + [C2H5COOH]/[H3O+]) … (*)

Or d'après le résultat : pH = pKA + log([C2H5COO-]/[C2H5COOH]) ; alors [C2H5COOH]/[C2H5COO-] = 10^(pKA − pH) … (**)

On remplace (**) dans (*), on aura l'expression : τ = 1/(1 + 10^(pKA − pH))

A.N : τ = 1/(1 + 10^(4,9 − 2,9)) ≈ 9,9.10-3 ≈ 1%

2-2-1- Equation chimique de la réaction du dosage :

C2H5COOH(aq) + HO-(aq) → C2H5COO-(aq) + H2O(l)

2-2-2- Recherche de l'expression du rapport [C2H5COO-]/[C2H5COOH] :

- Tableau d'avancement :

| Equation de la réaction | C2H5COOH(aq) + HO-(aq) → C2H5COO-(aq) + H2O(l) | | | |
| --- | --- | --- | --- | --- |
| Etat du système | Avancement x (mol) | n(acide) | n(HO-) | n(C2H5COO-) |
| Etat initial | 0 | CA.VA | CB.VB | 0 |
| Etat intermédiaire | x | CA.VA − x | CB.VB − x | x |
| Etat équivalence | xE | CA.VA − xE | CB.VB,E − xE | xE |

- Avant l'équivalence VB < VB,E, le réactif limitant est HO-(aq) : n(HO-) = CB.VB − x = 0 ⇒ x = CB.VB
- D'après le tableau : [C2H5COO-] = x/(VA + VB) et [C2H5COOH] = (CA.VA − x)/(VA + VB)

Et le rapport s'écrira : [C2H5COO-]/[C2H5COOH] = CB.VB/(CA.VA − CB.VB)

Or au point d'équivalence, la relation qui se réalise est : CA.VA = CB.VB,E

- L'expression finale est : [C2H5COO-]/[C2H5COOH] = VB/(VB,E − VB)

2-2-3- Vérification du pKA du couple C2H5COOH / C2H5COO- :

- La fonction pH = f(log(VB/(VB,E − VB))) est affine d'équation : pH = a.log(VB/(VB,E − VB)) + b … (1)

Où b représente l'ordonnée à l'origine, et graphiquement il vaut : b ≈ 4,9

- En comparant la relation (1) avec celle donnée à la réponse de la question 2-1-2- :

pH = log([C2H5COO-]/[C2H5COOH]) + pKA ; On déduit alors pKA ≈ 4,9

2- Oscillations libres dans le circuit RLC :

2-1- Recherche de l'expression de l'énergie magnétique Em(t) :

Soit une bobine de coefficient d'auto-inductance L, traversée par un courant d'intensité i(t) à l'instant t, et la tension entre ses bornes est uL(t) : la puissance instantanée est alors : p(t) = u(t).i(t)

Dans la convention « récepteur » la tension s'écrit : uL(t) = L.di(t)/dt

Donc p(t) = L.(di(t)/dt)×i(t) = (L/2).d(i2(t))/dt ou bien p(t) = d((1/2).L.i2(t))/dt … (1)

2-2- Recherche de l'expression d(ETot(t))/dt :

- L'énergie totale emmagasinée dans le circuit RLC est : ETot(t) = Eél(t) + Em(t)

Ou bien ETot(t) = (1/2).C.uc2(t) + (1/2).L.i2(t)

- Dérivons cette expression :

d(ETot(t))/dt = C.uc(t).duc(t)/dt + L.i(t).di(t)/dt

Or uc = q/C et duc/dt = (1/C).dq/dt = i/C, donc :

d(ETot(t))/dt = i(t).(q(t)/C + L.di(t)/dt) … (*)

Et d'après la loi d'additivité des tensions :

uc + ub + uR0 = 0 ⇒ q/C + r.i(t) + L.di(t)/dt + R0.i(t) = 0 ⇒ q(t)/C + L.di(t)/dt = −(r + R0).i(t)

On remplace cette dernière expression dans la relation (*) :

d(ETot(t))/dt = i(t).[−(r + R0).i(t)]

Finalement on aboutit à l'expression finale : d(ETot(t))/dt = −(r + R0).i2(t)

#### PARTIE II : Détermination du rayon de l'orbite de la lune autour de la terre

1- Définition : Le référentiel géocentrique est un référentiel dont l'origine est le centre de la Terre et dont les trois axes pointent vers des étoiles lointaines qui apparaissent fixes.

2- Le bon choix est : d) La vitesse d'une planète autour du soleil ne dépend pas de la masse de cette planète.
(a) Unité de la constante gravitationnelle N.m2.kg-2 ; b) Le vecteur accélération est radial mais non tangentiel ; c) Le vecteur accélération change de direction durant le mouvement circulaire uniforme).

3- Expression vectorielle de la force de gravitation : Dans (u⃗ ; n⃗) on a : F⃗S/T = G.M.m/R2 . n⃗

4- Le mouvement de la terre est circulaire uniforme :

- Système à étudier : {Terre (m)}
- Repère d'étude (S, i⃗, j⃗) supposé galiléen ;
- Bilan des forces extérieures : F⃗S/T
- La 2ème loi de Newton s'écrit : F⃗S/T = m.a⃗G ou bien m.a⃗G = G.M.m/R2 . n⃗ alors a⃗G = G.M/R2 . n⃗

Ce qui prouve que le vecteur accélération est radial, et que sa composante tangentielle est nulle, aT = dv/dt = 0 : On en déduit que la vitesse est constante ou le mouvement est uniforme.

D'autre part aG = aN ⇒ G.M/R2 = v2/R ⇒ R = G.M/v2 = Cte : On en déduit que le rayon est constant ou le mouvement est circulaire.

Finalement le mouvement de la terre par rapport au soleil est circulaire uniforme.

5- La troisième loi de Kepler : T2/R3 = K = Cte

Puisque le mouvement de la Terre par rapport au Soleil est circulaire uniforme de période T ; alors : T = 2π.R/v avec v = √(G.M/R) ; ce qui donne T = 2π.√(R3/(G.M)) ou T2 = 4π2.R3/(G.M)

Finalement la loi de Kepler est : T2/R3 = 4π2/(G.M) … (1)

6- * Expression du rayon orbital de la lune :

- On applique la loi de Kepler, pour le mouvement de la Lune par rapport à la Terre qui est circulaire uniforme de période T' : T'2/r3 = 4π2/(G.m) … (2)

- Des deux relations (1) et (2), on peut écrire : M.T2/R3 = m.T'2/r3 = 4π2/G

- On en déduit l'expression du rayon : r = R.((T'/T)2.(m/M))^(1/3)
