2-

| Équation chimique | $CH_3COOH_{(aq)} + H_2O_{(l)} \rightleftarrows CH_3COO^-_{(aq)} + H_3O^+_{(aq)}$ | | | |
|---|---|---|---|---|
| État | Avancement | Quantités de matière en mol | | |
| Initial | 0 | $C_1.V$ | En excès | 0 / 0 |
| Final | $x_{éq}$ | $C_1.V - x_{éq}$ | En excès | $x_{éq}$ / $x_{éq}$ |

On a : $K_A = \dfrac{[CH_3COO^-]_{éq}.[H_3O^+]_{éq}}{[CH_3COOH]_{éq}}$ ; D'autre part : $\tau_1 = \dfrac{x_{éq}}{x_{max}}$

D'après (T.A) : $[H_3O^+]_{éq} = \dfrac{x_{éq}}{V}$ ; Donc : $x_{éq} = [H_3O^+]_{éq}.V$ ;

D'autre part, puisque $CH_3COOH$ est le réactif limitant et en considérant la réaction totale, on a $C_1V - x_{max} = 0$ ; Donc : $x_{max} = C_1V$ ;

Par suite : $\tau_1 = \dfrac{[H_3O^+]_{éq}.V}{C_1V}$ ; Donc : $[H_3O^+]_{éq} = \tau_1.C_1$

D'après (T.A) : $[H_3O^+]_{éq} = [CH_3COO^-]_{éq} = \tau_1.C_1$

Donc : $K_A = \dfrac{(\tau_1.C_1)^2}{C_1.(1 - \tau_1)}$ ; Alors : $K_A = \dfrac{C_1.\tau_1^2}{(1 - \tau_1)}$ — 0,5

3-1 On a $\tau \ll 1$ ; Donc : $K_A = C_2.\tau^2$ ; Et on a : $C_2 = \dfrac{C_1.V_1}{V_1 + V_e}$

## Exercice 4 : Electricité

1- Détermination des caractéristiques de la bobine

1-1- D'après la loi d'additivité des tensions : $u_L + u_R = E$ ;

Donc $r.i + L\dfrac{di}{dt} + u_R = E$ ;

$\dfrac{du_R}{dt} + \dfrac{R + r}{L}u_R = \dfrac{R.E}{L}$

## Exercice 5 : Mécanique

Partie 1 : Mouvement d'un ballon de basket-ball

1- Système étudié : {le ballon} ; $\vec{P}$ : Le poids

Dans un référentiel terrestre, considéré galiléen, on applique la $2^{ème}$ loi de Newton : $\vec{P} = m.\vec{a}_G$ ; Donc : $m.\vec{g} = m.\vec{a}_G$ ; D'où : $\vec{a}_G = \vec{g}$

Projection suivant $(OX)$ et $(OZ)$

$\vec{a}_G \begin{cases} a_x = \dfrac{dv_x}{dt} = 0 \\ a_z = \dfrac{dv_z}{dt} = -g \end{cases}$ ; $\vec{v}_G \begin{cases} v_x(t) = \dfrac{dx}{dt} = v_0.\cos(\alpha) \\ v_z(t) = \dfrac{dz}{dt} = -g.t + v_0.\sin(\alpha) \end{cases}$

$\overrightarrow{OG} \begin{cases} x(t) = v_0.\cos(\alpha).t \\ z(t) = -\dfrac{1}{2}g.t^2 + v_0.\sin(\alpha).t + H \end{cases}$

Donc : $t = \dfrac{x}{v_0.\cos(\alpha)}$ ; Alors : $z(x) = -\dfrac{g}{v_0^2\cos^2(\alpha)}.x^2 + \tan(\alpha).x + H$ — 0,5
