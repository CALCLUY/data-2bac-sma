Partie 1 : Etude d'une solution aqueuse d'acide éthanoïque

1- $CH_3COOH_{(aq)} + HO^-_{(aq)} \rightarrow CH_3COO^-_{(aq)} + H_2O_{(\ell)}$ — 0,25

2-

| Équation chimique | $AH_{(aq)} + HO^-_{(aq)} \rightarrow A^-_{(aq)} + H_2O_{(\ell)}$ | | | |
|---|---|---|---|---|
| État | Avancement | Quantité de matière en mol | | |
| Initial | 0 | $C_A.V_A$ | $C_B.V_B$ | 0 (En excès) |
| Final | $x_f$ | $C_A.V_A - x_f$ | $C_B.V_B - x_f$ | $x_f$ |

Pour $V_B < V_{BE}$ ; $HO^-$ est le réactif limitant ; donc : $C_B.V_B - x_f = 0$

D'où : $x_f = C_B.V_B$ ;

D'autre part, à l'équivalence : $C_A.V_A = C_B.V_{BE}$ ;

D'après le tableau d'avancement : $[AH] = \dfrac{C_A.V_A - x_f}{V_A + V_B}$ ; donc : $[AH] = \dfrac{C_B.(V_{BE} - V_B)}{V_A + V_B}$

Et $[A^-] = \dfrac{x_f}{V_A + V_B} = \dfrac{C_B.V_B}{V_A + V_B}$ ; Alors : $\dfrac{[A^-]}{[AH]} = \dfrac{V_B}{V_{BE} - V_B}$ — 0,5

3- Pour $V_B = \dfrac{V_{BE}}{2}$ ; on a : $\dfrac{[A^-]}{[AH]} = 1$ ; d'où : $\log\left(\dfrac{[A^-]}{[AH]}\right) = 0$

Alors : $C_A = 10^{-2}\ mol.L^{-1}$

D'autre part : $\dfrac{C_0}{C_A} = 100$ ; donc : $C_0 = 100.C_A$ ; $C_0 = 100 \times 10^{-2}$

Alors : $C_0 = 1\ mol.L^{-1}$

## Exercice 4 : Electricité

Partie 1 : Réponse d'un dipôle RL à un échelon de tension

1-1- D'après la loi d'additivité des tensions : $u_L + u_R = E$ ;

Donc $r.i + L\dfrac{di}{dt} + u_R = E$ ; D'où : $r.u_R + L\dfrac{du_R}{dt} + R.u_R = R.E$

$\dfrac{du_R}{dt} + \dfrac{R + r}{L}u_R = \dfrac{R.E}{L}$ — 0,25

1-2- On a : $u_R = U_p.(1 - e^{-t/\tau})$ ; donc : $\dfrac{du_R}{dt} = \dfrac{1}{\tau}.U_p.e^{-t/\tau}$

D'où : $\dfrac{1}{\tau}.U_p.e^{-t/\tau} + U_p.\dfrac{R+r}{L} - U_p.\dfrac{R+r}{L}.e^{-t/\tau} = \dfrac{R.E}{L}$

Pour que cette égalité soit vérifiée à chaque instant, il faut que : $\begin{cases} U_p.\dfrac{R+r}{L} = \dfrac{R.E}{L} \\ \dfrac{1}{\tau} - \dfrac{R+r}{L} = 0 \end{cases}$

Alors : $U_p = \dfrac{R.E}{R+r}$ et $\tau = \dfrac{L}{R+r}$ — 0,25 / 0,25

2- On a : $u_R = U_p.(1 - e^{-t/\tau})$ ; Donc : $u_R - U_p = U_p.e^{-t/\tau}$ ;

D'où : $Ln(u_R - U_p) = Ln(U_p) - \dfrac{1}{\tau}.t$

D'autre part $Ln(u_R - U_p) = f(t)$ est une fonction affine d'équation : $Ln(u_R - U_p) = \alpha t + \beta$

Par identification : $\begin{cases} Ln(U_p) = \beta \\ -\dfrac{1}{\tau} = \alpha \end{cases}$ ; Donc : $\begin{cases} U_p = e^{\beta} \\ \tau = -\dfrac{1}{\alpha} \end{cases}$ ; D'où : $\begin{cases} \dfrac{R.E}{R+r} = e^{\beta} \\ \dfrac{L}{R+r} = -\dfrac{1}{\alpha} \end{cases}$

Alors : $\begin{cases} r = R.(E.e^{-\beta} - 1) \\ L = -\dfrac{R+r}{\alpha} \end{cases}$ ; Graphiquement : $\beta = 2,3$ et $\alpha = \dfrac{\Delta Ln(u_R - U_p)}{\Delta t}$

$\alpha = \dfrac{0 - 2,3}{1,92.10^{-3}}$ ; $\alpha = -1198\ s^{-1}$

$r = 10 \times (12 \times e^{-2,3} - 1)$ ; Alors : $r = 2\ \Omega$

$L = -\dfrac{10 + 2}{-1198}$ ; $L = 0,01\ H$ — 0,25 / 0,25

3- On a : $E_m(t) = \dfrac{1}{2}.L.\left(\dfrac{u_R}{R}\right)^2$ ; Donc : $E_{m;max} = \dfrac{1}{2}.L.\left(\dfrac{U_p}{R}\right)^2$

D'où : $\dfrac{1}{2}.L.\left(\dfrac{U_p.(1 - e^{-t/\tau})}{R}\right)^2 = 0,8.\dfrac{1}{2}.L.\left(\dfrac{U_p}{R}\right)^2$

Par suite : $(1 - e^{-t/\tau})^2 = 0,8$ ; Donc : $1 - e^{-t/\tau} = \sqrt{0,8}$ ;

d'où : $e^{-t/\tau} = 1 - \sqrt{0,8}$ ; $t = \tau.Ln\left(\dfrac{1}{1 - \sqrt{0,8}}\right)$ ; Alors : $t = \dfrac{L}{R+r}.Ln\left(\dfrac{1}{1 - \sqrt{0,8}}\right)$

$t = \dfrac{0,01}{10 + 2}.Ln\left(\dfrac{1}{1 - \sqrt{0,8}}\right)$ ; $t = 1,87.10^{-3}\ s$ soit : $t = 1,87\ ms$ — 0,5
