#### 9-1/ Partie 1

1. Montrer que :

$$\forall x \in \left]\right. - \frac{\pi}{2} ; \frac{\pi}{2} \left[\right. ; \frac{1 + sin x}{cos x} = \frac{1 + tan \left(\frac{x}{2}\right)}{1 - tan \left(\frac{x}{2}\right)}$$

2. a- Montrer que pour tout $a \in \left[\right. 0 ; + \infty \left[\right.$ :

$$A r c tan \left(\sqrt{a} + \sqrt{a + 1}\right) = \frac{\pi}{4} + \frac{1}{2} A r c tan \left(\sqrt{a}\right)$$

b- En déduire que :

$$tan \left(\frac{5 \pi}{12}\right) = 2 + \sqrt{3}$$

#### 9-3/ Partie 3

Soit $f$ la fonction définie sur $\left]\right. - \infty ; \frac{\pi}{2} \left[\right.$ par :

$$\left\{\begin{matrix} f \left(x\right) = \sqrt[3]{1 - x} + x - 1 s i x < 0 \\ f \left(x\right) = A r c tan \left(\sqrt[3]{x} + tan x\right) s i x \in \left[\right. 0 ; \frac{\pi}{2} \left[\right. \end{matrix}\right$$

1. Montrer que la fonction $f$ est continue en $0$.

2. Calculer les limites suivantes :

$$\underset{x \rightarrow 0^{+}}{lim} \frac{f \left(x\right)}{x} ; \underset{x \rightarrow 0^{-}}{lim} \frac{f \left(x\right)}{x} ; \underset{x \rightarrow - \infty}{lim} f \left(x\right) ; \underset{x \rightarrow - \infty}{lim} \frac{f \left(x\right)}{x}$$

Soit $g$ la restriction de $f$ à l'intervalle $I = \left[\right. 0 ; \frac{\pi}{2} \left[\right.$.

3. Montrer que $g$ est strictement croissante sur $I$.

4. Montrer que $g$ est une bijection de $I$ sur $I$.

On note $g^{- 1}$ la fonction réciproque de $g$.

5. Résoudre dans $I$ l'équation $g^{- 1} \left(x\right) = x$.

6. Montrer que $\left(\forall x \in I\right) g^{- 1} \left(x\right) \leq x$.
