#### 8-5/ Exercice 3-5

1. Simplifier les expressions suivantes :

$$A = A r c tan 2 + A r c tan \frac{1}{2} \\ \\ B = A r c tan \left(1 - \sqrt{2}\right) - A r c tan \left(1 + \sqrt{2}\right)$$

$$A r c tan \frac{1}{2} + A r c tan \frac{1}{3} = \frac{\pi}{4} \\ \\ A r c tan \frac{1}{2} + A r c tan \frac{1}{5} + A r c tan \frac{1}{8} = \frac{\pi}{4} \\ \\ 4 A r c tan \frac{1}{5} - A r c tan \frac{1}{239} = \frac{\pi}{4}$$
